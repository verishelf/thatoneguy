# That Guy! — Junk Hauling

Professional marketing website for **That Guy!**, a local junk hauling service based in Chula Vista, California.

## Features

- Clean, modern single-page design
- Hero section with clear CTAs
- Services grid (residential, commercial, construction, appliances, yard waste, estate cleanouts)
- “Why Us” + How It Works
- Service area coverage (Chula Vista & South Bay)
- Contact / free-quote form (client-side; ready to wire to a backend)
- Fully responsive (mobile-first)
- SEO-friendly metadata

## Tech Stack

- **Next.js 16** (App Router)
- **React 19**
- **TypeScript**
- **Tailwind CSS v4**

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build for Production

```bash
npm run build
npm start
```

## Deploy

The easiest way to deploy is with [Vercel](https://vercel.com):

1. Push this repo to GitHub
2. Import the project in Vercel
3. Deploy
